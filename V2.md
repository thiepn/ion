# ION V2 — independent modern racing foundation

**Development branch:** `feature/ion-v2-modern-racing-foundation`

The existing HexGL-based public site on `main` is deliberately untouched. V2 is a new playable vertical slice, not a CSS redesign of the legacy runtime.

## What is implemented

- React 19, React Three Fiber 9, Three.js modern WebGL, TypeScript and Vite.
- Original elevated closed-loop spline circuit; its render geometry, closest-point collision, checkpoint and lap calculations all share the same course.
- An independently built hovercraft with authored geometry, animated engine glow, banking/hover motion, chase cameras, camera FOV response, and built-up industrial skyline.
- Keyboard (WASD / arrow keys), gamepad and on-screen touch input; throttle, braking, steering, boost, collision response, shield damage, checkpoints, boost-pad recharge and three-lap time trial.
- Countdown, paused/resumed sessions, restart, finish and destruction screens; timing, locally stored personal best lap, sector tracking and speed/boost/shield HUD.
- Reduced-motion compatible UI, responsive touch controls, scalable render quality.
- No external textures, tracks, 3D models, servers, analytics or user accounts are needed for this vertical slice.

## Run locally

```sh
npm install
npm run dev
# Open the Vite URL
```

Verify production build with `npm run build`. Cloudflare Pages is configured to run `bash scripts/build.sh` and serve `dist/`; the build script in this development branch runs the modern application build.

## Engineering status and limitations

This is a **first playable modern foundation**, not the fully finished upgraded ION. It is intentionally asset-independent and uses code-built geometry instead of claiming to be a high-detail commercial 3D racer.

Before production promotion:
- Conduct an actual browser playthrough, test lap completion, collision/boost behavior, mobile touch and different GPUs, and fix any defects.
- Improve the race environment with licensed PBR textures and detailed original/CC0 vehicle and architectural models.
- Add audio, quality scaling, loading/error handling, race-session persistence and high-quality effects.
- Review colors, lighting, framerate and controls on real mobile and desktop devices.
- Keep the legacy HexGL branch for comparison; no direct game assets or gameplay source were copied into V2.

## Architectural note

`src/simulation.ts` owns racing rules/controls. `src/track.ts` owns course geometry/projection. `src/World.tsx` renders and animates the scene. `src/App.tsx` is the declarative accessible interface. Avoid duplicating these authorities as the game expands.
