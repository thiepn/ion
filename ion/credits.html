ANTI-GRAVITY RACING · CREDITS AND LICENSING

ION is a modified presentation of HexGL, originally created by Thibaut Despoulain (BKcore). The original driving engine, race track and vehicle assets are retained. Original in-game credits are also preserved.

Original code and resources

HexGL's repository describes code and resources as MIT-licensed unless an individual file specifies otherwise. See the original MIT LICENSE and copyright notices in source files. For example, bkcore/hexgl/HexGL.js includes a CC BY-NC 3.0 notice. That exception means the whole bundle should not be assumed cleared for commercial use.

ION modifications

ION changes the game's title, site metadata and interface presentation, and removes the original Google Analytics tracker. It currently does not claim newly authored original vehicle models, racing physics, or tracks.

Source attribution is retained in recognition of the game's authors and license obligations. For noncommercial personal play; obtain separate permissions before assuming broader asset licensing.
