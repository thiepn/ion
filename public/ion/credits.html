V2 development

The modern course, racing simulation, vehicle geometry, environment and interface on the V2 branch are independently authored for ION. This development build uses Three.js, React, React Three Fiber and Vite; their respective published open-source license terms apply.

Kenney Space Kit — V4 CC0 models

V4 includes a small, pinned subset of Kenney's Space Kit, published under CC0 1.0 Universal. Kenney's original meshes were repackaged as self-contained GLBs by Hidencod/tge-assets. ION verifies an exact Git source revision and individual model hashes during the Cloudflare build. Models are used for circuit structures, aerial traffic, stations and the optional Rift racer; all original ION track/collision systems remain ours.

V4 asset provenance, complete manifest and source revisions. The models are CC0; any independent assets in the legacy HexGL version retain their original licenses.

HexGL reference and legacy version

ION originated as a customization of HexGL by Thibaut Despoulain (BKcore). Its legacy build remains preserved on the original production `main` branch and in repository history. HexGL source/resource licensing defaults to MIT unless a file states otherwise. Some legacy source files carry CC BY-NC 3.0 notices and several audio clips carry CC BY 3.0 obligations; these restrictions should be reviewed independently before legacy asset reuse or commercialization.

The V2 gameplay and visual runtime does not incorporate the legacy vehicle, track, audio or source files. HexGL's original copyright notices remain in the legacy Git history and source references.
